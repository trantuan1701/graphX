02 / GRAPHX VS GRAPHFRAMES

Iterative PageRank

Cùng công thức, khác cách gắn rank nguồn và cập nhật state.

r′(v) = (1 − d)/N + d [ Σu→v r(u)/outDegree(u) + D/N ]d = 0.85 · rank ban đầu = 1/N · 5 vòng

GraphX

// g: rank ở vertex, 1 / outDegree ở edge
val messages = g.aggregateMessages[Double](
  e => e.sendToDst(e.srcAttr * e.attr),
  (a, b) => a + b,
  TripletFields.Src
)
val next = g.outerJoinVertices(messages) {
  (_, _, msg) =>
    teleport + d * (msg.getOrElse(0.0) + share)
}

GraphFrames

// state: id, rank; weightedEdges: src, dst, weight
val graph = GraphFrame(state, weightedEdges)
val messages = graph.aggregateMessages
  .sendToDst(AggregateMessages.src("rank") *
    AggregateMessages.edge("weight"))
  .agg(sum(AggregateMessages.msg).as("message"))
val next = state.select("id")
  .join(messages, Seq("id"), "left")
  .select(col("id"), (lit(teleport) + lit(d) *
    (coalesce(col("message"), lit(0.0)) +
      lit(share))).as("rank"))

D là dangling mass. teleport = (1 − d)/N, share = D/N. Đoạn trích minh họa một vòng cập nhật.

HI-Small - local[2] - run 179315779254507 / 12
Đây là PageRank tự triển khai qua aggregateMessages, không gọi built-in pageRank của GraphFrames hay GraphX. D được tính mỗi vòng bằng tổng rank của vertex outDegree=0. Hai bên đều giữ mọi vertex, kể cả isolated và vertex không có message. Weight = 1/outDegree, giữ cạnh song song và không dùng amount. Code minh họa bỏ out_degree trong output GF vì chỉ thể hiện contribution/update; implementation đầy đủ giữ out_degree cho vòng kế tiếp. Timer thật còn có dangling reduction, checkpoint và cleanup state cũ. 5 vòng không chứng minh hội tụ. Nguồn: notebook 03 pageRankStep, frameStep, preparePageRank và prepareFrame.

03 / GRAPHX PARTITION STRATEGIES

Partition Strategies: Theory & Scala Code

Giữ nguyên GraphX và phần cứng, chỉ thay strategy và số partition.

RandomVertexCut

Hash cặp (src, dst). Baseline cùng P.
Không tối ưu trực tiếp số bản sao vertex.

EdgePartition1D

Hash theo src, gom cạnh cùng nguồn.
Có thể lệch tải khi nguồn có nhiều cạnh.

EdgePartition2D

Ánh xạ nguồn và đích vào lưới 2D.
Giới hạn replication lý thuyết ≤ 2⌈√P⌉.

GraphX: một API, ba lựa chọn

Vertex-cut chia cạnh thành partitions, vertex có thể xuất hiện ở nhiều edge partition. Edge-cut chia vertex thành tập và cắt cạnh nối các tập. Tên EdgePartition1D/2D không biến chúng thành edge-cut. GraphFrames repartition(src) là phân phối DataFrame, không tương đương API chiến lược edge-cut đầy đủ. Deck không đo vertex-cut vs edge-cut. Với P=4 và16 là số chính phương, bound2sqrt(P)=4 và8. Chặn lý thuyết không có nghĩa đo thực sẽ chạm bound hay2D thắng. vertexRDD và edgeRDD là RDD input chung, tương ứng v và e ở slide build.
